# Tokyo Flight Deals ✈️🇯🇵

Python project to find cheap return flights from London to Tokyo (and maybe other airports in Japan) and send me a notification when there is a really good deal.

This is an improved version of my original `flight-deals` exercise, but this time I want to make it actually useful for me and have it running automatically.

### What I want it to do

* Search from any London airport
* Search Tokyo (Haneda or Narita), and possibly other airports in Japan
* 1 person, economy, return flight
* Look at different dates rather than one specific trip
* Find flights under a price I consider a good deal
* Send me a Telegram notification when it finds one
* Run automatically so I don't need to check flights myself

### What I'm using

* Python
* Flight search API
* Telegram Bot API
* GitHub Actions for running it automatically
